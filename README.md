## Dataset
CRMLS (California Regional Multiple Listing Service) files from May 2025 - June 2026
- Categorical features: City, County , District
- Numerical features: Living Area, Bedrooms, Bathrooms, Lot Size, Year Built, Bed-Bath Ratio, Lot Area Ratio, Age of Property, Relative Size (County)
